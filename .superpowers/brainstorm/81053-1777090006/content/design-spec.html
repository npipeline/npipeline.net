Final Design: NPipeline Homepage

Refined B — Split Hero + Horizontal Flow. Full design specification below.

Overall Visual Language

Color palette
Design principles
  • Dark immersive (#001219 base) — Filigran-inspired
  • Small radius (6px default) — per user preference
  • Full-bleed sections, no visible card borders
  • Large varied typography, generous whitespace
  • Parallax on hero + feature cards
Color usage
  • #0A9396 — Primary accent, headings, links
  • #EE9B00 — CTAs, highlights, warm accent
  • #94D2BD — Secondary text, body copy
  • #E9D8A6 — Highlighted text, emphasis
  • #BB3E03 → #9B2226 — Pain points, errors
  • #005F73 — Gradients, subtle backgrounds

Technical Architecture

  • Framework: React Router v7 + Mantine 9 + @gfazioli/mantine-parallax
  • Theme: Mantine createTheme with palette colors, defaultRadius "sm" (smaller corners)
  • Layout: Single-page scroll with section components in app/sections/
  • Parallax: Used on hero container, 3 pipeline cards, resilience card
  • Navigation: Mantine AppShell with sticky header + anchor links
  • Animations: Mantine Parallax for 3D hover, scroll-based background shifts via useWindowScroll
