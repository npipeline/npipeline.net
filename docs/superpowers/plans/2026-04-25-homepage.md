# NPipeline Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dark-immersive, Filigran-inspired homepage for NPipeline using Mantine components and Mantine Parallax, targeting .NET developers and data engineers.

**Architecture:** Single-page scroll layout composed of 10 section components under `app/sections/`, a `Header` component, and a `HomePage` composer. Mantine theme is customized with the ocean color palette and small radius. Mantine AppShell provides the sticky header shell. Parallax wraps the hero, pipeline cards, and resilience card for 3D hover effects.

**Tech Stack:** React 19, React Router v7, Mantine 9, @gfazioli/mantine-parallax, TypeScript
